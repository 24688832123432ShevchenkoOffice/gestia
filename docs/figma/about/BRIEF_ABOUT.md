- Помилки/неоднозначності макета не виправляти — дописати в docs/figma/OPEN_QUESTIONS.md (розділ «Про нас»).
- Шапку/футер/блоки, що вже є в проєкті (header, footer, відгуки, популярні товари, картки товарів з головної) — ПЕРЕВИКОРИСТАТИ існуючі partials/CSS. Спільні файли (base, CSS-база, шапка/футер) змінювати мінімально.
- Inter 400/500, border-radius 0, без тіней, контейнер 1302px.
- Мобільного макета «Про нас» у фреймі «Мобільна правкі 3» НЕМАЄ (є лише Головна, Бургер, Каталог, Фільтри, Товар). Тому mobile (≤ 393px): коректне стискання за патернами вже зверстаних мобільних сторінок (мобільна головна: шапка, відгуки, популярні, футер), без вигаданих елементів. Записати це в OPEN_QUESTIONS.
- Відео-банер: картинка imgVideoBanner + іконка imgVideoIcon як у макеті (без реального відео, якщо в проєкті нема механізму).
- Без секретів, .env не читати, не пушити, не комітити (коміт зробить оператор).
- Перевір: python manage.py check та тести, якщо доступні без .env.
