# Gestia — QA-звіт і виправлення (28.10.2026)

Середовище: локальний dev (`config.settings.develop`, SQLite, DEBUG=True), Mac, Playwright 1.64 (Chromium / Firefox / WebKit headless), Django test client, raw HTTP (urllib). Гілка `main`, базовий HEAD `c592463`. Push і деплою не було. Тестові замовлення з dev-БД видалено, ціни й наявність відновлено.

## 1. Архітектура і ризикові місця
- Додатки: `src/catalog` (Category, Product, ProductSet, атрибути, фільтри в `selectors.py`), `src/commerce` (кошик у сесії `cart.py`, `services.create_order`, форми з валідацією `validators.py`, Нова Пошта `novaposhta.py` з demo-режимом), `src/content` (головна, про нас, юридичні сторінки), `src/core` (i18n-middleware, перемикач мови/валюти, robots, 404).
- Кошик: `request.session["cart"] = {sku: qty}`, MAX_QTY=99 (`src/commerce/cart.py`).
- Залишок: **кількості на складі немає** — тільки `Product.stock_status` (in_stock / on_order / out) (`src/catalog/models.py`). Сценарій «залишок = 1» у поточній моделі неможливо реалізувати → відсутнє / рекомендовано.
- Ризики до виправлень: `views.checkout` / `buy_now` → `services.create_order` не перевіряли наявність і активність товару, не мали ідемпотентності; `cart.lines` мовчки викидав неактивні товари; номер замовлення `token_hex(2)` (65 536 на день → колізія unique → 500); `thanks` показував будь-який `?number=`; `home` не приймав HEAD (405); `SESSION_COOKIE_SAMESITE=Strict` у prod; немає canonical/OG/sitemap; HTMX-помилки мовчазні; EN-переклади неповні.
- Мови: у `LANGUAGES` лише **uk і en**. RU відсутня (`/ru/` → 404) → відсутнє / рекомендовано (продуктове рішення).
- Окремої сторінки контактів немає (`/kontakty/` → 404); контакти в футері/«Про нас» → відсутнє / рекомендовано, якщо потрібна окрема.
- Адмінка за стандартною адресою: **так** (рекомендовано змінити). DEBUG у production: вимкнено (`config/settings/production.py`).

## 3. Виняткові сценарії Gestia
1. Сет «Великодній Український» (GH-01) у кошику, адмін ставить «Немає в наявності» → checkout відмовляє з назвою товару (🔧).
2. Клієнтка приходить з Instagram за посиланням на товар → на prod зі Strict-cookie кошик «губився» (🔧 Lax).
3. Ім’я з апострофом ’ / ʼ / ' (Ол’га, О'Браєн) і подвійне (Анна-Марія) — проходить; емодзі й цифри — ні.
4. Телефон, вставлений як 0671234567 / 380671234567 → нормалізується; київський 044 — відхиляється (лише мобільні коди).
5. Зміна валюти UAH/EUR між відкриттям checkout і submit → cart_sig не збігається → «Кошик або ціни змінилися» (🔧).
6. «Замовити одразу» через HTMX подвійним тапом на iOS → одне замовлення (idem + data-once) (🔧).
7. Святкові бокси ще не в продажу → модалка waitlist (email), EN-переклад (🔧).
8. Нова Пошта в demo-режимі: міста/відділення/вулиці відповідають; без ключа й без demo → 503 `not_configured`.
